# AI Coding Test Trainer

AI 기반 코딩테스트 학습 플랫폼

단순히 문제를 푸는 공간이 아니라,  
**AI를 활용해 개인 맞춤형 코딩테스트 훈련을 제공하는 학습 서비스**를 목표로 합니다.

---

## 프로젝트 소개

이직 준비 과정에서 느낀 문제에서 시작했습니다.

AI 시대가 왔지만, 상향 지원을 위해서는 여전히 코딩테스트가 중요한 평가 요소입니다.

하지만 기존 코딩테스트 학습 방식에는 몇 가지 아쉬움이 있었습니다.

- 하루 학습량을 스스로 통제하기 어렵다.
- 틀린 문제를 체계적으로 복습하기 어렵다.
- 현재 내 실력에 맞는 문제를 찾기 번거롭다.
- 풀이 접근이 맞는지 중간 피드백을 받을 수 없다.
- 학습 기록이 단순 리스트 형태라 성장 흐름이 잘 보이지 않는다.

이 프로젝트는 이런 문제를 해결하기 위해 시작했습니다.

---

## 목표

### 1. 제한된 학습량 기반 루틴 형성

하루 최대 2문제만 풀 수 있도록 제한하여  
무리한 문제 풀이보다 꾸준한 학습 습관 형성을 목표로 합니다.

---

### 2. AI 기반 문제 생성

사용자가 원하는 난이도와 알고리즘 유형을 선택하면  
AI가 해당 수준에 맞는 새로운 코딩테스트 문제를 생성합니다.

예시:

- Level 1 문자열 문제
- Level 2 해시 문제
- Level 2 스택 / 큐 문제

---

### 3. AI 힌트 시스템

사용자가 작성한 코드를 기반으로  
정답을 직접 알려주지 않고 학습 방향을 제시합니다.

예시:

- 현재 접근 방식은 맞습니다.
- 시간복잡도가 비효율적일 수 있습니다.
- Map 자료구조를 활용해보세요.
- 특정 반례를 생각해보세요.

---

### 4. 틀린 문제 복습 시스템

실패한 문제를 자동으로 저장하고  
나중에 다시 복습할 수 있도록 관리합니다.

---

### 5. 학습 히트맵 시각화

GitHub 잔디 형태의 히트맵으로  
꾸준함과 학습 기록을 시각적으로 확인할 수 있도록 합니다.

---

## 문제 생성 전략

기존 코딩테스트 플랫폼의 문제를 그대로 가져오는 방식이 아닌  
AI를 활용한 신규 문제 생성 방식을 채택합니다.

이유:

- 외부 플랫폼 콘텐츠 의존성 제거
- 저작권 / 정책 이슈 회피
- 사용자 수준 맞춤형 문제 제공
- 무제한 문제 확장 가능

문제 생성 과정:

```txt
AI 문제 생성
→ AI 정답 생성
→ 테스트 케이스 생성
→ 내부 검증
→ 사용자 노출
```

## AI 힌트 정책

AI는 학습 보조 도구이며 정답 제공 도구가 아닙니다.

- 자료구조 추천
- 알고리즘 힌트 제공
- 반례 유도
